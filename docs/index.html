01

Source

One method, fills the buffer. Who fills it is the caller's business.

The crate is one contract: give me bytes. @system.source is the platform's — crypto.getRandomValues on JavaScript, WASI's random_get on wasm, the runtime on native.

Replay hands back the bytes it was given, in order, until it runs out. Your own implementation can be a device, a service, a file. Three kinds of source, one method.

There is no fallback. That is not a promise in the prose, it is in the type: the call raises, the signature says so, and the caller cannot miss it.

02

Start

Three lines. No init, no global state, no generator to construct first.

// thirty-two uniform bytes; a negative length aborts let key = @moonseed.bytes(32, @system.source) // in [0, 1000), as wide as the bound let n = @moonseed.below(b"\x03\xe8", @system.source) // in [1, 4): a key, a nonce let d = @moonseed.scalar(b"\x05", @system.source)

03

Sampling

Rejection, not modulo. Modulo favours the small values; not doing that is why this function exists.

below(bound) reads its bound as a big-endian number: draw exactly as many bytes as bound−1 needs, clear the unused high bits of the first, and draw again while the value is at or above bound. Every value is equally likely.

scalar(order) gives you something in [1, order) — a private key, a nonce. Draw as wide as order, draw again while the value is zero or not below order: FIPS 186-5 A.2.2, the same draw Go's ECDSA makes. A P-521 scalar is 66 bytes with the top bits clear, which is why this cannot be "ask for 32 bytes".

Both read-outs are pinned to fixed byte streams: the same bytes, read by an independent implementation of the same rule, give the same number, and every byte is accounted for.

// below(1000): 999 needs 10 bits, draw 2 bytes loop { source.fill(draw) // two bytes draw[0] = draw[0] & 0x03 // clear the top six let v = be(draw) if v < 1000 { return v } } // fewer than two draws on average

below(1 << k) never redraws — the mask already fits. Only a bound that is not a power of two pays for the loop.

N uniform bytes, no more and no fewer. A negative n is a caller's mistake, so it aborts rather than pretend to hand back nothing.
pub fn[S : Source] below(bound : BytesView, source : S) -> Bytes raise Unavailable
[0, bound), as wide as the bound. Mask the unused high bits, redraw while at or above bound. A bound of 1 reads nothing; zero aborts.

[1, order), as wide as the order. Keep the leftmost bits, redraw on zero or overflow: the FIPS 186-5 A.2.2 draw.

05

Limits

It is not a generator, and does not pretend to be one.

01

No generator

No seed, no stream, no "same seed gives the same numbers". For a reproducible stream, use moonrand. Keeping these apart is what stops either from deciding for you.

02

No WASI, no bytes

The root package touches no platform. Linking system links the platform's one call. A wasm host without WASI uses the root package and a source of its own.

03

No retry, no stretching

One call, one answer; whether to retry is the caller's policy. It moves entropy, it does not stretch it — 32 bytes do not become a 64-byte secret.

frosted · partition
It keeps no secret

It takes bytes from a source and hands them over. The buffer is yours to wipe or not; this crate does not allocate a cache or keep a copy.

No side-channel story

The rejection loop leaves a timing trace. Constant time is the caller's problem: bound the retries, or sample differently.

The platform is not verified

@system.source reports what the platform says. It does not judge whether the platform is compromised. That trust sits in the OS, not here.
